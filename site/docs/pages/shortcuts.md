# Shortcuts

These keyboard shortcuts work in the Editor. Press `?` in the Editor for its live list, which always matches your version.

Ctrl/⌘ means Ctrl on Windows and Linux, and ⌘ on a Mac. Alt is Option on a Mac. A key does nothing while you type in a text box.

## Add and draw

| Action                   | Keys                                |
| ------------------------ | ----------------------------------- |
| Add a box                | `N` or double-click                 |
| Add a connected box      | `Shift Enter`                       |
| Add a box in a direction | `Alt` + arrow                       |
| Add the next box         | `Tab`                               |
| Add a sibling box        | `Shift Tab`                         |
| Insert a step on a line  | `Tab`, with the connection selected |
| Build from a list        | `B`                                 |
| Draw a box               | `R`                                 |
| Draw an ellipse          | `O`                                 |
| Draw a diamond           | `D`                                 |
| Draw text                | `T`                                 |
| Draw a container         | `G`                                 |
| Connect (stays active)   | `C`                                 |

To connect from the keyboard, select a source, press `C`, press `Tab` to reach the target, then press `Enter`.

## Select and edit

| Action                   | Keys                           |
| ------------------------ | ------------------------------ |
| Edit mode                | `V`                            |
| Return to Edit mode      | `Escape`                       |
| Edit a label             | `Enter` or double-click        |
| Select more objects      | `Shift` + click                |
| Select an area           | `Shift` + drag                 |
| Select everything        | `Ctrl/⌘ A`                     |
| Pin or unpin             | `P`                            |
| Nudge by 1               | Arrow keys                     |
| Nudge by 10              | `Shift` + arrow                |
| Keep a container on drag | `Alt` + drag                   |
| Wrap in a container      | `Ctrl/⌘ G`                     |
| Ungroup                  | `Ctrl/⌘ Shift G`               |
| Duplicate                | `Ctrl/⌘ D`                     |
| Copy and paste           | `Ctrl/⌘ C` and `Ctrl/⌘ V`      |
| Copy as an image         | `Ctrl/⌘ Shift C`               |
| Delete                   | `Delete` or `Backspace`        |
| Delete with children     | `Shift Delete`                 |
| Undo                     | `Ctrl/⌘ Z`                     |
| Redo                     | `Ctrl/⌘ Shift Z` or `Ctrl/⌘ Y` |

## Zoom and pan

| Action                    | Keys                                    |
| ------------------------- | --------------------------------------- |
| Fit the diagram           | `1`                                     |
| Zoom to 100%              | `0`                                     |
| Zoom in                   | `+` or `=`                              |
| Zoom out                  | `-`                                     |
| Zoom at the pointer       | Wheel or pinch                          |
| Zoom to an area           | `Ctrl/⌘` + drag                         |
| Pan mode                  | `H`                                     |
| Pan                       | Drag the background, or `Shift` + wheel |
| Pan for a moment          | `Space` + drag                          |
| Pan with nothing selected | Arrow keys                              |

## Layout and routing

| Action                       | Keys               |
| ---------------------------- | ------------------ |
| Tidy current positions       | `L`                |
| Preview automatic layout     | `Shift L`          |
| Layout settings              | `Alt L`            |
| Compare layouts              | `Alt E`            |
| Layout timeline              | `Alt T`            |
| Layout brush                 | `W`                |
| Brush size, in brush mode    | `[` and `]`        |
| One brush dab                | `L`, in brush mode |
| Restore while brushing       | `Alt` + drag       |

| Automatic ports on selection | `Alt Shift R`      |
| Lock a connection side       | `Alt` + port drag  |
| Mark as the start            | `Alt S`            |
| Mark as the end              | `Alt End`          |

## Panels and files

| Action                  | Keys        |
| ----------------------- | ----------- |
| Show the list           | `?`         |
| Objects panel           | `[`         |
| Inspector               | `]`         |
| Hide or restore panels  | `\`         |
| Diagrams in this folder | `F`         |
| Go to a diagram         | `Ctrl/⌘ P`  |
| Save                    | `Ctrl/⌘ S`  |
| Open a diagram          | `Ctrl/⌘ O`  |
| Previous or next state  | `[` and `]` |

`Ctrl/⌘ P` needs a folder that `draftably open` serves. Without one, the browser prints as usual. `[` and `]` step through [emphasis states](#emphasis-states) when the file has them, and move the panels otherwise.
