# Choose a path

Draftably turns short text into laid-out diagrams. Pick what you want to do.

## Make a diagram

- **Try it now, no install.** [Get started](#get-started) walks through a first diagram in the
  browser, then on disk.
- **Learn the language.** [Rules](#rules) lists every statement. [Examples](#examples) shows
  finished diagrams with their source.
- **Pick a diagram kind.** [Swim lanes](#swim-lanes), [sequence diagrams](#sequence-diagrams) and
  [cells](#cells) for grids and bit layouts.

## Work with files

- **Edit `.draft` files and check them in CI.** [CLI](#cli) shows each command in use. The
  [CLI reference](#command-line) lists every option.
- **Have a coding agent draw for you.** Install the [agent skill](#agent-skill).
- **Bring diagrams you already have.** [Import](#import) DOT, Mermaid and D2 files.

## Put diagrams in your product

- **Already use Mermaid?** [Switch from Mermaid](#from-mermaid) with one alias. Your page code
  stays the same.
- **Show diagrams in an app.** Use the [framework components](#frameworks) or the
  [element](#element). Add the [editor](#editor-component) to let users change them.
- **Draw diagrams in docs.** [Markdown](#markdown) fences, [documentation sites](#documentation-sites)
  and the [GitHub Action](#github-action) for READMEs.

[Embed diagrams](#embed) compares every route on one page.
