'draftably': patch
---

`draftably pdf` and the viewer's PDF export no longer start Chrome. PDFKit draws each page from the same SVG, with the bundled fonts, selectable text, working links, bookmarks and attached sources, so PDF export needs no browser. A contents page now holds only the rows that fit, so `--page fit` and `--page slide` covers no longer cut off the last entries.
