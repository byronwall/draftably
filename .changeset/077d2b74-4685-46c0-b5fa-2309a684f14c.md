'draftably': patch

Comparison panels now reuse the merged drawing's line routes, so every line both versions keep runs in the same place in each panel. The change key is one row with counts (`3 added · 1 changed · 2 removed`), and `draftably compare` prints the same counts on stderr.

`draftably compare` now splits an edge that joins different objects into a removed and an added line, so the older panel draws the line it had, and it names nodes or groups that moved to another container.
