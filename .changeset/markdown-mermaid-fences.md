New `mermaid: 'convert'` option for the remark and markdown-it adapters. A `mermaid` fence that holds a flowchart or sequence becomes the same static SVG image as a `draft` fence, with no Mermaid in the browser. Pie, gantt and every other Mermaid family stay code blocks for the site's Mermaid setup.
