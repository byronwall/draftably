Edit code tables in the Editor: double-click a code node to edit its body on the canvas. A `table=on` node opens as a grid of cells, with Tab and Enter moving between cells and a spreadsheet paste filling them. Paste spreadsheet cells or a Markdown table on the canvas to add a table node. Code tables also read pasted Markdown and psql tables with their `:---:` alignment and `(3 rows)` footer, the header rule is softer and ends at the last column, and a code caption band has a light tint.
