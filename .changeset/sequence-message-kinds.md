Sequence diagrams say what each message is. An edge takes message=interaction, call, send, reply or outcome, a reply names the message it answers with reply-to=, and an action line draws work one participant does as a box on its lifeline. The drawing adds a key for the marks in use. Headers are compact, a label between distant participants sits in one gap clear of every lifeline, and a long phase label wraps.
