Drag into intent
In interactive mode, drag a box or a group header. Relative drag writes a near relationship, soft offset writes nudge, and pin writes parent-local coordinates.
near payments orders
  side=right gap=32
The example above is shown wrapped for readability. This prototype requires one complete statement per line.
Layout has scopes
Select a container, choose its layout, and reflow only that scope. Select a leaf to edit the recipe of its parent. The root recipe arranges top-level groups.
layout root flow direction=auto
layout services grid columns=2
order services api jobs store
align x api store strength=required
Add without resetting everything
Add component captures explicit soft stays for currently automatic nodes before adding a node and an edge. Existing authored relative hints and pins remain. Stays resist movement, but yield to non-overlap.
Exact versus adaptable
Checkpoint stores the current boxes in the source. A matching input replays them exactly. Change the model, context, or hints and the checkpoint is ignored, never silently stretched.
Source is the authority
Every geometric preference is in the DSL. Camera zoom, selection, and undo history are editor state. Export the DSL and a fresh browser can reproduce the layout without your edit log.
Minimal syntax
diagram "An example" version=1
node a "Input" kind=app
node b "Output"
edge e a -> b "flows"
layout root row gap=48
view explore "Explore" mode=interactive width=900 height=500
More hints
nudge b dx=0 dy=24
stay a x=0 y=0 weight=8
pin a x=0 y=0
size b width=220 height=90
near b a side=right gap=40
align y a b strength=prefer
Add view=explore to a layout or hint to restrict it to that view. Global hints otherwise apply to all views.
This is an experimental compiler, not ELK or a general constraint solver. Routing is heuristic, pairwise hints are sibling-scoped, and some constraint sets are impossible. Diagnostics disclose failures rather than hiding them.
