# Curated source and review appendix

This appendix preserves the workstreams’ original evidence and the input instructions without packaging downloaded full article caches or historical authoring programs. The final per-case files and root reports are authoritative for completion, final ratings and global gap IDs.

| Folder | Contents and use |
| --- | --- |
| `source-context/` | Byte-identical copies of the attached mission, supplied baseline identity, and repository instructions. The baseline application itself was not changed. |
| `readlogs/` | Original workstream reading records, preserving the distinction between full-file and targeted reads. The consolidated reading route is `../source-read-log.md`. |
| `findings/` | Detailed E01–E10, E11–E22 and E23–E30 observations. Local provisional gap keys are intentionally retained; use the root gap audit for the final merged taxonomy. |
| `reviews/` | Independent implementation-plan review, independent visual review of infrastructure cases, and concrete false positives/blind spots in the historical geometry audit, and the rerun-helper failure-propagation review. These are reviews of evidence and proposals, not executed product changes. |
| `proofs/` | The concept workstream’s final source/original/freeze verification. The complete corpus gate is `../logs/final-verification.json`; all command logs remain under `../logs/`. |
| `candidates/` | Original workstream selection and rejection fragments. The root `candidate-log.csv` is the consolidated register. |
| `licenses/` | Observed primary repository license text for Crafting Interpreters, React documentation and Pro Git. These snapshots do not establish rights for unrelated references. Each case retains its own source attribution and observed-license boundary. |

`copy-provenance.json` identifies every byte-identical copy, its source path and SHA-256. The adjacent readlog is an explicitly labeled excerpt. No original reference artwork or native attempt is replaced by this appendix.

## License evidence scope

Crafting Interpreters’ repository distinguishes source-code licenses from prose/illustration licenses; the retained PNG references are covered by the stated illustration terms, not the code’s MIT license. React and Pro Git snapshots are repository documentation-license evidence. Other references may have page-wide notices or unknown figure-specific reuse terms, as recorded in `../sources.csv` and each `source.md`. Public availability was not treated as permission. Public redistribution review remains unexecuted; no authors were contacted and no public corpus was published.
