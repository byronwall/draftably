# Editorial diagram corpus

This study compares Draftably with deliberate editorial diagrams from primary internet sources.
It measures native fidelity, first-render quality, authoring effort, and recurring capability gaps.

The corpus contains 30 external references, 90 native attempts, and 60 full/detail comparison sheets.
All 90 attempts were replayed locally. Their geometry and SVG bytes match Pro's results exactly.

The study covers 22 independent publisher groups and 16 overlapping pattern families.
It includes 22 computing examples and eight adjacent examples. Every accepted reference has its
original media, attribution, three native attempts, renders, effort counts, and an audit.
The source selection excludes default automated-engine galleries.

The baseline is `f14d9b891adba75de6cc172b190017ea5a5ca091`.
The renderer and language stay fixed during evaluation. Product fixes require later work.

## Reading the result

Start with the gallery or summary. The original report contains the detailed thirty-case ledger.
The final ZIP is kept in ignored storage and linked from the run record and chat.
Its root contains the original study. `codex/` adds local replay output and the integration review.

Scores are visual judgments. Command exits, geometry, source counts, and hashes are measured.
The study makes no pixel-perfect, measured authoring-time, or tested edit-resilience claim.
Source licenses vary. Preserve each source record and check its terms before further image reuse.

The existing [quality rubric](../diagram-quality/RUBRIC.md) helps find drawing defects.
This study adds external design references and authoring-cost evidence.
