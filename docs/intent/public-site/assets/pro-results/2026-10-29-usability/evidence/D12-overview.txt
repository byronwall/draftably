Overview

A .draft file is a readable diagram source that a person and an agent can both edit. It holds the model (objects, groups, connections), the automatic layout recipe, and layout refinements. It never holds a picture of the final layout: the same file always compiles to the same geometry.

Views and checkpoints are not supported yet.
