Layout tools

A rebuild arranges a scope from scratch, so it is saved as a recipe. Preview automatic layout in Layout options, and every rebuild candidate in Compare, compile the file with the new layout line. What you see is exactly what the file will draw, and Keep or Apply saves that line. Soft position refinements inside the scope are removed so the engine's arrangement shows; pins, sizes and the nested groups' own layout lines stay. Layout options shows the scope's current line and the one a rebuild would write. The routing menu and routing comparisons write the routing line.

Tidy positions, Preview tidy, a kept timeline step, a brush stroke, and warm-start or pass candidates in Compare all start from the current drawing, so a recipe could not reproduce them. They are saved as an arrangement instead: each object that moved gets a soft stay at its new position relative to its parent (an existing stay is updated in place), and the objects around them are anchored as for a drag. Groups follow their contents, so a group whose children moved left or up moves with them. Pins never move. A root-level stay may be negative, because the root has no frame.

Checkpoints are unavailable while a file is open, because undo steps through the file's versions. Connection bends, label positions, start/end preferences and images are unavailable because the file cannot store them yet.
