Rules

Write one statement per line. Indentation means nothing; containment comes from in=. Strings use JSON double quotes. Inside a string, write \" for a quote, \\ for a backslash and \n for a line break: node n "Says \"hi\"". A bare quote inside a string is an error that names its column. IDs match [A-Za-z_][A-Za-z0-9_.-]* and must be unique across nodes and groups. References may point to later lines.

Statement	Meaning
diagram "title" version=1	Optional title. At most one. Exports and the viewer draw it above the drawing. width= sets the frame's width.
compare "before" "after"	Draw the change marks as two aligned panels. direction=right|down, aspect=. At most one.
subtitle "text"	One line under the title. At most one.
node id "label"	A shape. in=group, color=, shade=, shape=box|pill|circle|diamond|text|marker, href=, count=.
group id "label"	A container. in=group, color=, shade=, frame=box|soft|none, fold=never. See Soft groups.
theme name	The diagram's theme and diagram-wide overrides. See Themes and colors.
theme-color family	One shade of a color family. See Themes and colors.
legend family "meaning"	One row of the color key: a swatch of family (shade= optional, 500 by default) and what it means. See Themes and colors.
note "text"	A sentence on the diagram that never moves anything. near=id side=below|above|left|right puts it beside an object; without near it sits under the subtitle. width=. See Notes.
edge id source -> target "label"	A connection between two nodes, or a node and a boxed group (the line ends on the group's frame). kind=async draws it dashed; from=/to= choose sides; constraint=false draws it without letting it rank or order anything (for feedback edges).
layout scope flow|row|column	How a scope (root or a group) arranges its direct children. gap=, direction=auto|right|down, min-width=, min-height=.
layout root lanes	Swim lanes: each top-level group is a lane. See Swim lanes.
layout root sequence	A sequence diagram: nodes are participants, edges are messages in file order. See Sequence diagrams.
layout group cells	The group's nodes touch, edge to edge, as one object. columns=, unit=byte|bit. See Cells.
layout scope engine=name	Arrange a scope's whole subtree with a layout engine. See Layout engines.
layout root … fit=slide	Aim the drawing at a shape: wide (2:1), slide (16:9), square, page (portrait) or tall. Compile also lays it out reading the other way and with folding on and off, keeps the closest, and says which in an info note.
routing	Router settings for every connection. See Routing.
config key=value	File settings. See Links and counts.
state id "label" ids...	A named emphasis state. See Emphasis states.
phase id "label" message ids...	Sequence diagrams: a run of messages drawn as a row band. See Sequence diagrams.

Colors are covered in Themes and colors. An auto color inherits the family of the nearest colored group. Without a layout line, root uses flow gap=48 and groups use column gap=24.

flow ranks objects along its direction by their connections. A loop keeps its path in that direction, and only the edge that closes it runs backwards. A run of ranks that is wider than the canvas (1100×720) and more than three times longer than it is deep folds into rows (or columns, for direction=down) that each start again at the beginning, like lines of text. fold=never keeps it on one line. engine=layered folds the same way unless it has fold=never. Where to fold is decided without edge labels, so labelling or relabelling an edge keeps every object in its row; labels only widen the gaps they need, and add a row only when the labelled rows run more than a quarter past the canvas.

Under engine=layered or engine=compound-flow, a drawing that holds groups is packed instead: a drawing wider than the canvas and more than five times longer than it is deep first folds its longest group into rows, one group at a time, so the groups keep their order; only if no group can fold do the groups themselves wrap into rows. A group that only receives lines (an upstream API, a cache) sits beside the group that calls it rather than past it. fold=never on the root engine keeps one long line. Stays and pins never change what folds.

Title and subtitle. inspect --svg, the viewer's SVG and PNG exports and the viewer's canvas draw the diagram title and the subtitle line above the drawing, left-aligned with the legend, in one frame round the drawing, so a copied image still says what it shows and why it matters. Like the legend, they never move anything. A file without either draws no heading. The frame is as wide as the drawing, the heading and the legend; width= on the diagram line makes it wider (diagram "Checkout" version=1 width=900), for a long subtitle or room on the right.

Notes. note "A plan is one pricing tier: Free, Team or Enterprise." adds a sentence that defines a term or explains the drawing. Like the legend, a note never moves anything. Without near= it sits in the frame under the subtitle; several notes stack in file order. With near=id it is placed after layout beside that node or group: side=below (the default), above, left or right, at the first spot along that side that is clear of shapes, lines, group borders and other notes. A note wraps at 280px; width=80..1200 changes that. check warns (note-overlap) when an anchored note found no clear spot.

Copy
note "Seats are billed monthly." near=seat side=below width=220

Links and counts. href="src/api.ts" on a node or group makes it a link in inspect --svg and exports, to a source file, a URL or anything else the reader should open. A linked object draws a small ↗ mark at its top-right corner (beside a container's title). In the viewer the mark is the open button, and the Inspector shows the link with an Open button; a click elsewhere on the object still selects it. The link opens as written: a URL (https://…, a GitHub link) in a new tab, a .draft in the viewer, and a file path in VS Code. A file path may end in :42 or :42:5 to open at that line and column. A relative path starts at the diagram's git root, or its folder outside a repository.

In inspect --svg and the viewer's SVG export, each linked object is an <a> with a tooltip naming its target, and its outline thickens on hover. A URL stays as written and opens in a new tab. A file link is written as a path from the diagram's folder, without its line, so it opens when the SVG is saved beside the .draft. Each object's group carries data-id with its ID.

config lines hold file settings. One line may set several keys, or each key may have its own line; a key set twice is a warning and the later line wins.

Copy
config link-base="../.." editor=cursor

link-base is where relative links start, relative to the .draft file's folder, for a diagram whose paths don't start at the git root. It may also be a URL, such as source pinned at one commit, config link-base="https://github.com/org/repo/blob/<sha>/": then href="src/parser.py#L40" joins it, opens as a web link and is written that way into SVG and PNG exports. check doesn't look for those files on disk. editor is the editor file links open in: vscode (the default), vscode-insiders, cursor, windsurf or zed. check warns about a relative link whose file does not exist at the link base, and suggests the path it probably meant: the same path from the diagram's folder, or the one file in the repository whose path ends the same way. It never changes the link.

count=42 on a node says the box stands for 42 things: it draws as a stack with a ×42 badge, so a component used in hundreds of places is one box rather than hundreds. When there is no real number to show, give a letter or short word instead: count=N draws ×N, and count=many draws ×many.
