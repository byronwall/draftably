examples/ holds the bundled diagrams, from flat flows to five levels of containers. They are bundled into the viewer, so they open without a server at ?example=id. An example is a scratch copy: an amber Example bar stays across the top, the toolbar reads Example · not on disk, and nothing is written anywhere. Edits behave exactly as in a file. Save as file… writes the current source to a new file in the served folder and opens it; on the static site the bar offers Download .draft instead. Leaving an edited example asks first.

The file is the source of truth while it is open: browser storage is not read or written, and moving the camera never changes the file.

--png <file> on inspect or compare saves a PNG at --scale times the SVG's size (2 by default) and prints its size in pixels. --max-width <px> lowers the scale so the image is at most that wide. It renders with an installed Chrome, Chromium or Edge in headless mode; set CHROME_PATH to use another copy.

inspect uses the editor's own router and the same font tables, so its geometry matches the viewer. inspect --svg draws with the file's theme and embeds its fonts.
