Agent skill
Agent skill

Draftably ships a skill that teaches coding agents such as Claude Code to write .draft files, check them, pick a layout and hand the result to you in the editor. The agent edits text, so its diagrams diff and review like code.

Install it
Copy
npx draftably skill install                       # ./.claude/skills/draftably
npx draftably skill install --global              # ~/.claude/skills/draftably
npx draftably skill install --dir .agents/skills  # any other skills folder
npx skills add byronwall/draftably                # or straight from the repository

--force replaces a copy that is already there. npx draftably skill print prints the skill so you can read it first.

What the agent does with it

The skill gives the agent one loop, and each step is a CLI command:

Plan the model. List the boxes, the groups they belong to and the connections, with short IDs and human labels.
Write the file: declarations, then edges, then layout lines.
Check it with draftably check. Every warning names the IDs, and a conflict that a refinement caused names its line and a fix.
Let the tool choose the layout with draftably vary, which ranks layout variants on a contact sheet, then vary --apply best.
Look at it with inspect --svg or --png, and review check --metrics.
Hand it over with draftably open, so you can see it and drag things into place. Your edits save to the same file the agent reads.
Ask for a diagram

Once the skill is installed, ask in plain words:

Copy
Draw the checkout flow in src/checkout as a .draft file next to it, and open it for me.

The agent writes the file, runs check until no error is left, and prints the editor's URL.

The skill's full text is skills/draftably/SKILL.md. It covers the syntax, layout engines, cells and refinements.
