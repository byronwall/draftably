## Root causes, ranked for round 2

1. **Flow collapses cycles into one layer** (`engine-order`, 4 diagrams, the worst reading-order
   failures). `rankLayers` in [src/dsl/compile.ts](../../../../src/dsl/compile.ts) ranks
   strongly connected components, so a single feedback edge (verify → analyzer, more → job,
   review → merge) puts the whole loop in one layer. A `direction=right` pipeline turns into a
   column (decisory, add-metric), and `direction=down` into a row (release). Fix: break cycles
   at their back edges (declaration order, or DFS) and rank what remains, so the loop's return
   edge runs backwards instead of folding the path.
2. **Labels don't fit their edges, so they drift** (`label-placement`, 80 detached, 29 on other
   edges, 12 diagrams). Flow and layered gaps (48px) ignore label width. A label longer than its
   edge is lifted about 45px above it, or moved onto a different line ("pick a path", "valid",
   "story ids"). Fix: grow a gap to fit the widest label crossing it (label-aware rank gap),
   and never place a label where another edge runs.
3. **Lines run too close to boxes and borders** (`routing-clearance`, 436 hugs, 66 hooks, 43
   along group borders). The router keeps lines 10–13px off box sides. U-turns between stacked
   neighbours, and lines squeezed between rows, sit right against the boxes. Fix: raise the
   default clearance (or the standoff for parallel runs) to at least 20px, prefer the facing
   side for stacked neighbours instead of U-turning out the side, and keep runs out of
   group-border bands.
4. **Exports clip what leaves the box area** (`export-bounds`, 13 clipped items, S1). The SVG
   viewBox is computed from nodes only. Fix: include route points and label boxes in the bounds.
5. **Long chains never fold** (`recipe-default`): ingest is 15:1, ci-checks 10.8:1, deploy 9.4:1.
   A 12-node pipeline at docs width shrinks to unreadable. Fix: let `layered` and `flow` fold a
   long rank sequence (the engine has `fold=auto`; check why it doesn't apply here) once the
   aspect passes about 3:1.

Next in line: staggered group members in compound-flow, theme switches that move the layout,
mid-word wraps of long identifiers, near-identical dark shades.

## Metric changes this round

- Added **clearance** metrics (`edge-hugs-node`, `edges-too-close`, `edge-on-group-border`) after
  review feedback that lines run too close to boxes. Thresholds were checked against the CI
  example (lines 10–13px off box sides).
- Added `keeps-order` and a shift-aligned move count: growing a group legitimately pushes its
  neighbours, as in hn-offline e2, where everything moved about 100px but nothing swapped order.
- Fixed four expectations that were authoring mistakes, not tool defects: grow follow-ups now
  use `keeps-order` instead of `still *`; CI's order check skipped the proofs branch; the
  reading flow had no declared direction, and the default reads left to right.
- False alarms left in: `above components state` on the stress layout (stress has no direction;
  the expectation assumed one). Drop it next round. The `near done more 120` failure is a 121px
  gap, which is fine.

## Color findings

- `theme-color` custom families work and look good (file-session, decisory).
- Shade ramps fail above 600: neighbouring dark shades are indistinguishable in signal,
  midnight and fieldnotes (amber turns muddy brown).
- Changing only the `theme` moves the layout when fonts differ. A recolor or theme request
  should never move anything.
- Recolors through `color=` alone moved nothing (node-tree e2, mcp-call e2).
- No contrast failures: built-in shades always choose readable ink.

## Process notes

- Viewer drags work as designed: a drag writes `near` plus `stay` anchors, and the `# expect`
  comments survive the save. `draftably open` needs `pnpm build` first in a fresh worktree.
- Four expectations were authoring mistakes and were fixed before scoring. Of the 20 that still
  fail, two are false alarms (code-layers' direction on a stress layout) and one is a 1px miss.
  Expectations need the same care as the diagrams.
- The sheet images are good for an overview. Score from the single PNGs.
