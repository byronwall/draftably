# Use Draftably in your project

Choose the integration that matches where diagrams render. The guides below include setup and
host-specific limits. Their source is in
[`site/docs/pages/`](../../site/docs/pages/).

- [Embed diagrams](https://draftably.dev/docs/embed): choose between a static image, a page viewer,
  or a framework component
- [Switch from Mermaid](https://draftably.dev/docs/from-mermaid): replace Mermaid in an app, a CDN
  page, a Markdown build, or hosted Markdown
- [Choose how to embed](https://draftably.dev/docs/embed): React, Solid, Vue, Svelte and plain HTML
- [How embedding works](https://draftably.dev/docs/embed-concepts) and the
  [API reference](https://draftably.dev/docs/api-reference)
- [Editor component](https://draftably.dev/docs/editor-component)
- [Render SVG](https://draftably.dev/docs/render-svg)
- [Markdown](https://draftably.dev/docs/markdown): Unified, MDX and markdown-it build pipelines,
  file assets, Mermaid fences and interactive enhancement
- [Documentation sites](https://draftably.dev/docs/documentation-sites): Astro Starlight,
  Docusaurus and VitePress
- [GitHub Action](https://draftably.dev/docs/github-action)
- [Support](https://draftably.dev/docs/support)
- [Build an adapter](https://draftably.dev/docs/build-an-adapter)
